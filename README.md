# 📚 Trabalhos-Academicos-LaTeX

Bem-vindo ao repositório de templates para documentação acadêmica. O objetivo é compartilhar estruturas prontas para agilizar a escrita de trabalhos, relatórios e apresentações, seguindo boas práticas e normas (como ABNT).

---

## 📂 Estrutura do Repositório

O conteúdo está organizado por tipo de documento e formato:

- **/tcc** — Estruturas para Monografias e TCCs.
- **/relatorios** — Relatórios técnicos, aulas práticas e projetos.
- **/slides** — Templates para apresentações (LaTeX Beamer, Markdown/Reveal.js, PPTX).
- **/artigos** — Artigos científicos e resenhas.
- **/bmr** — Modelos para BMR (Boletim de Medição de Resultados) e métricas.

---

## 🛠 Formatos Suportados

- **LaTeX** — Foco em tipografia matemática e científica.
- **Markdown** — Documentação rápida e conversão via Pandoc.
- **DOCX/ODT** — Para editores de texto convencionais.
